# Start Here

This is my Digital Garden — a place for notes, journal entries, and technical documentation.

## How This Garden Works

Notes published from Obsidian appear here automatically.

To publish a note from Obsidian:
1. Add `dg-publish: true` to the note's frontmatter
2. Use the **Digital Garden plugin** in Obsidian to sync
3. The note will appear in the file tree on the left

## Folder Structure

```
Journal/
  ├── Home.md          ← This site's home page
  ├── Start Here.md    ← This note
  ├── Daily/           ← Daily journal entries
  ├── Technical/       ← Code, commands, how-tos
  ├── Projects/        ← Project documentation
  └── Ideas/           ← Experiments and half-formed thoughts
```
