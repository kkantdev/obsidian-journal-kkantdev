# 🚀 SlideCast - beta



> [!abstract] Overview
> 
> **SlideCast** is an **offline-first Windows desktop presentation app** built with Flutter. It lets presenters load presentation slides (PDFs, images, or PowerPoint files) and control them using any mobile phone connected to the same Wi-Fi or hotspot—without requiring internet, cloud services, or app store downloads..

## 📥 Download & Installation

Click the button below to get the latest Windows release:

> [!tip] Quick Download
> 
> 💾 **[Download SlideCast-v1.1.0 for Windows (64-bit) ↗](https://github.com/kkantdev/kkantdev-application/releases/download/v1.1.0-beta-slidecast/Slidecast-setup-v1.1.0.exe)**
> 
> _Version:_ `v1.1.0` | _Platform:_ `Windows 10 / 11` | _File Type:_ `.exe`

### ⚙️ Quick Installation Steps

1. **Download** the `.exe` installer using the link above.
    
2. **Run** the installer file (`SlideCast-Setup.exe`).
    
3. If Windows Defender shows a prompt, click **More Info** $\rightarrow$ **Run Anyway**.
    
4. Follow the on-screen instructions to complete the setup.
    
5. Launch the app from your Start Menu or Desktop shortcut!
