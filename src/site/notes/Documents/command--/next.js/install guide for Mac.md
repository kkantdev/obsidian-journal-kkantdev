If you want to check your Mac is on ARM64 or X 64 run this command in the terminal, and you can see 

```
uname -m
```


Then install the note from this website for Mac
[node](https://nodejs.org/en/download)


After installing the note in the Terminal, you can copy paste this command and see if verify that it is installed or not 
```
node -v
npm -v

```
